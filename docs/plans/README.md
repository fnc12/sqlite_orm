# Design plans

A design plan for work in progress goes here, named `YYYY-MM-DD-<topic>.md`.

A plan describes the code as it was when it was written, so it is kept only while its work is
open. When the work is done, its lasting reasoning moves into code comments or
[the internals documentation](../internals/home.md), and what remains into the PR description;
then the plan is deleted. Git history keeps it.
